# MyCleaner International  ltd

lav europas fedste provider platform indenfor c2c home service,  understøtte priser, valuta og satser i hvert enkelt land  i europa. fuld onboarding setup for provideer der skal godkendes inden de kan tage opgaver, kunden skal udfylde profil med adresse, bolig mv for blive matchet bedst muligt også for kunden får vist tilbud der har relevant for. dem med deres pris fudfra registeret opgave dynamiske tilbud slå vises til kunden, dynamiske beskeder,, hilsner, push og notfikatiner.  

europas smarteste og mest eftertrycket platform, med ask hjælp alle steder det giver mening og er muligt.  

admin system der kan styre og se alt.  derudover skal vi have login til medarbejder som  holder styr på providee og kunder, løser problemer, og alt køre som det skal. 

alt betalining giennem stripe (nøgle gives senere ) auto split payment til provider og platform,  platform, gebyr 25% deles mellem kunder og provioder..  

provider kan tilkøbe boost af profil for blive mere synlig 
provider kan oprette sig som private udbyder elller som virksohed  ( som virksomhed koster det oprettelse samt månedlig gebyr der betales kvartalsvis forud. for x antal områder) 

ai pris forslag, ai Aris beregner,,   


der må ikke være budkrig, under betaling, betalinger skal være være og ligger på eller omrkings markeds pris.  ingen underbetaling  min , betasling efter overenskomst i hver land.
